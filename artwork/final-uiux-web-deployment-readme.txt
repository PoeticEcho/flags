꼬마 세계 탐험대 · 최종 UI/UX 업데이트 (2026-10-03)

이 ZIP은 웹 서버에 바로 올릴 수 있는 빌드된 앱입니다.
압축을 풀고 index.html, assets, flags, data 등의 파일과 폴더를 웹 루트에
동일한 구조로 업로드하세요. 파일을 두 번 클릭하는 file:// 실행은 지원하지 않습니다.
별도의 Node.js 설치나 npm 빌드 없이 정적 HTTPS 웹 서버에서 사용할 수 있습니다.

197개국 + 그린란드 + 남극 = 199개 탐험지
한영 이야기 995쌍, 주요 태그 1,990쌍, 모든 엽서를 포함합니다.
남극은 대륙이며 그림에 쓰인 깃발은 비공식 상징입니다.

변경 사항
- 탐험을 새로 켜면 직전에 보던 곳을 제외한 무작위 탐험지에서 시작합니다.
- 색칠·내 국기 화면은 작업하던 나라와 저장한 그림을 이어서 엽니다.
- 퀴즈에 세 개의 탐험 별, 이번 탐험 정답 수, 재도전 칭찬을 추가했습니다.
- 정답 후 0.9초 축하 반응 뒤 다음 문제로 자동 진행하며 직접 다음도 가능합니다.
- 퀴즈 소리는 기본 꺼짐이며 소리 아이콘으로 선택해 켤 수 있습니다.
- 오답 뒤 같은 질문의 다른 보기와 핀을 바로 선택할 수 있습니다.
- 모바일 상단 아이콘과 개인 카드 버튼, 저장 이름과 팝업 초점을 정리했습니다.
- 태그를 누르면 기존 나라·수도 우선 검색으로 바로 이어집니다.
- 긴 저장·영어 도구 이름이 버튼 안에서 줄바꿈되며 검색 Escape 뒤 팝업이 다시 열리지 않습니다.
- 지도 미지원 기기에는 나라 카드와 이름 퀴즈를 안내합니다.
- 이전 진입 파일 경로를 새 앱으로 연결해 배포 교체 시 빈 화면을 방지합니다.
- 공식 국기 페인트통은 화살표로 영역을 선택하고 Enter/Space로 채울 수 있습니다.

진행과 작품은 사용 중인 브라우저 기기에 저장됩니다.
다른 기기나 도메인으로 자동 이전되지 않습니다. 작품은 SVG로 별도 내려받을 수 있습니다.
지도와 3D 펄럭임은 지원되는 그래픽 환경이 필요하며, 펄럭임에는 평면 대체 표시가 있습니다.
검토 브라우저의 WebGL2 미지원으로 실제 지도 회전·핀·3D와 휴대폰 터치 검수는 완료되지 않았습니다.
저작권·출처 안내는 함께 포함한 data 폴더 및 각 자료의 라이선스를 참고하세요.
