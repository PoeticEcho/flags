새로운 곳에서 시작하되 그림은 이어서 작업

새 탐험은 199곳 가운데 직전에 보던 곳을 제외해 선택한다. 모든 나라가 대상이므로 그린란드·남극도 나올 수 있다. 색칠 또는 내 국기 화면에서 앱을 다시 열면 선택한 나라와 초안이 유지된다. 무작위 진입이 그림을 중단하거나 다른 나라의 색칠로 바꾸지 않도록 했다.

퀴즈는 작은 성공을 자주 보여주기

이번 방문의 정답 수와 세 개의 탐험 별을 표시한다. 맞히면 짧은 별 효과와 칭찬 후 0.9초 뒤 다음 문제로 이어진다. 직접 다음으로 넘길 수도 있다. 틀린 보기를 고르면 해당 보기와 배움의 힌트만 표시하고 다른 보기는 계속 선택할 수 있다. 벌점이나 제한 시간은 추가하지 않았다.

다시 도전한 성공은 별도로 칭찬한다. 새 탐험 도장 알림은 실제 새 도장이 생겼을 때만 표시한다. 같은 곳의 반복 정답이 전체 수집 도장을 중복으로 늘리지 않는다. 남극은 수도 문제 대신 기존 과학·자연 문제를 사용한다.

선택적 정답 소리는 기본 꺼짐이다. 버튼을 켰을 때의 정답 선택에서만 짧은 합성음을 만든다. 이번 검토에서는 기본 꺼짐, 켜기·끄기 표시, 이벤트·오디오 자원 수명 검사를 확인했다. 실제 소리의 음량·즐거움은 청취 평가하지 않았다. 움직임 줄이기 CSS는 유지했지만 실제 운영체제 설정으로 확인하지 않았다.

작은 화면과 긴 버튼 이름 정리

모바일 상단은 네 모드·검색·도장·언어 전환의 일곱 44px 조작으로 맞춘다. 언어는 한 개의 전환 버튼으로 줄인다. 퀴즈 설정은 줄바꿈하며 개인 카드의 편집·펄럭임·SVG·삭제는 아이콘과 고유 접근성 이름으로 표시한다.

최종 데스크톱 확인에서 나라 카드 저장, Save country, 영어 도구명이 좁은 버튼에서 잘리거나 옆 버튼과 겹치는 문제가 보였다. 저장 이름에 별도 텍스트 영역을 두고 버튼 안에서 줄바꿈하도록 수정했다. 아래 한영 최종 화면에서 잘림이 해소됐다. 긴 영어 단어는 글자 단위로 나뉠 수 있어, 후속 디자인에서 도구 팔레트 폭을 조정할 여지는 있다.

실제 320~600px 브라우저 뷰포트를 설정할 수 있는 기능은 이 검토 환경에 없었다. 브라우저 확대도 1363px 뷰포트를 바꾸지 않았다. 따라서 모바일 인구/퀴즈 겹침, 팝업 높이, 터치·핀치의 실기기 통과를 주장하지 않는다. 관련 CSS와 398개 한영 탐험 화면의 구조 검사는 통과했다.

검색·팝업·저장의 행동을 명확하게

태그 칩은 기존 검색으로 바로 연결한다. 나라·수도 결과가 항상 태그 결과보다 먼저 나오며 일치한 태그 이유를 표시한다. Escape로 검색을 닫은 뒤 초점을 돌릴 때 onFocus가 목록을 다시 열던 문제도 수정했다. 의도적인 다시 클릭이나 아래 화살표는 검색을 다시 연다.

엽서·카드 수집함·펄럭임 팝업은 닫으면 호출 버튼으로 초점을 돌려준다. 저장 버튼은 실제 행동에 맞춰 작품 저장과 나라 카드 저장으로 구분한다. 이름이 없는 개인 국기의 저장 안내와 입력 초점도 확인했다.

공식 국기의 페인트통은 화살표로 영역을 선택하고 Enter/Space로 채울 수 있다. 보호된 작은 문양은 건너뛴다. 선택 테두리는 실제 그림과 분리되어 채점·SVG·스포이드에 들어가지 않는다. 베트남의 두 영역을 실제 키보드로 채워 100%를 확인했다.

지도 미지원과 배포 교체에서 길을 잃지 않기

검토 브라우저는 WebGL2를 지원하지 않아 지도가 초기화되지 않았다. 미지원 안내에 나라 카드로 탐험과 이름으로 퀴즈하기를 제공하고 작동하지 않는 지도 조작은 숨겼다. 지도 문제는 이름 보기로 전환된다. 일반 데이터 로딩 오류의 재시도는 유지한다. 실제 반복 지도·핀·핀치·3D는 검증하지 못했다.

v29 교체 때 캐시된 이전 HTML이 삭제된 JS/CSS 경로를 요청해 빈 화면이 발생했다. 실제 404 경로에 현재 앱으로 연결하는 작은 호환 진입 파일을 제공했으며 v30에서 같은 일반 주소의 브라우저가 회복됐다. v31 첫 일반 주소 새로고침은 작동하는 v30 화면을 유지했다. 최종 v31 진입·새 줄바꿈·검색 닫기는 버전 확인 링크 ?v=31에서 실제 새 파일을 확인했다. 모든 브라우저 캐시가 즉시 갱신된다고 주장하지 않는다. _headers에 재검증 설정을 넣었지만 실제 응답 헤더 자체는 별도로 검사하지 않았다.
