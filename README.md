## 2026-10-22 수정 사항

- 직선 이동 시 선택 테두리의 여백 대신 실제 선 끝을 기준으로 제한해 국기 좌우·상하 끝에 닿도록 수정했습니다. 크기 조절·키보드 이동·실행 취소와 기존 그림 형식은 유지합니다.

- **내 국기 만들기 — 직선 구획 분할 및 폐곡선(닫힌 도형·곡선) 페인트통 채우기**: 직선(`선`) 도형으로 국기 바탕을 나누거나 직선끼리 만나 닫힌 다각형을 만들면 각 구획을 독립된 영역으로 인식해 페인트통과 그리기 도구로 서로 다른 색을 칠할 수 있으며, 크래용·색연필·사인펜으로 그린 닫힌 곡선(폐곡선) 안쪽도 페인트통으로 바로 채울 수 있습니다(`src/planar-regions.js`, `src/flag-art.js`, `src/custom-shapes.js`, `src/FlagStudio.jsx`).
- 전체 자동 검사 135개와 프로덕션 빌드를 통과했습니다. 이번 환경에서는 화면 미리보기 서버가 없어 직접 포인터·터치 조작 검수는 하지 못했습니다.

## 사용 방법

### 지도 탐험

탐험 모드로 앱을 다시 열면 199곳 중 무작위 장소에서 시작하며, 저장된 직전 장소는 가능한 한 제외합니다. 색칠·만들기 모드에서 다시 열 때는 작업 중인 나라와 그림을 복원합니다.

나라 이름, 수도, 별칭 또는 태그를 검색하세요. 한글·영어 모두 검색하며 **나라·수도 결과를 먼저, 태그 결과를 다음에** 표시합니다. 같은 장소는 한 번만 나타납니다. 예를 들어 `석회암` 또는 `limestone`으로 쿠바를 찾을 수 있고 같은 태그를 가진 다른 장소도 나옵니다. 카드의 태그를 눌러 검색을 이어갈 수도 있습니다.

지도는 앱에 포함된 Natural Earth 벡터 자료를 사용합니다. 검색한 나라로 이동하고 수도 핀·확대·축소·세계 반복을 지원하며 외부 지도 타일 API 키는 필요하지 않습니다. 카드에서는 이야기 두 화살표와 `1/5` 표시로 다섯 편을 읽습니다. 엽서 미리보기를 누르면 큰 그림을 불러오며 사진 재클릭, X, Escape 또는 바깥 클릭으로 닫습니다.

### 수도·지식 퀴즈

수도 문제는 정답과 같은 대륙의 실제 수도 두 개를 더해 A/B/C 세 보기로 구성합니다. 지도 핀과 이름 보기는 같은 도시·순서를 사용합니다. 문제를 풀기 전 정답 나라의 영역을 강조하지 않습니다. 남극은 가짜 수도 문제 대신 한영 과학·자연 지식 문제 5종을 사용합니다.

틀린 답을 고르면 해당 답의 힌트를 보고 같은 문제에서 다른 답을 바로 고를 수 있습니다. 맞히면 정답 수, 별, 재도전 칭찬과 실제 새 도장을 표시하고 **약 0.9초 뒤 다음 문제로 이동**합니다. 세 정답마다 탐험 별 세 개를 보여줍니다. 같은 나라의 반복 정답은 수집 도장을 중복으로 늘리지 않습니다. 선택적 정답 소리는 기본 꺼짐이며 사용자가 켜야 재생합니다.

### 국기 색칠

색칠할 나라를 검색하고 페인트통·크래용·색연필·사인펜·펜 지우개·스포이드를 선택합니다. 페인트통은 영역 전체를 채우고 그리기 도구는 시작 영역 안에서 실제 붓질을 남깁니다. 팔레트·사용자 색상·굵기·질감·실행 취소를 지원합니다.

흰 영역은 빈 종이도 정답으로 인정하고 아주 작은 보호 문양은 유지합니다. 페인트통은 키보드 화살표로 영역을 고르고 Enter/Space로 칠할 수도 있습니다. 채점한 실제 정답률이 90% 이상이면 칠한 국기를 펄럭여 볼 수 있습니다. 작품을 수정하면 다시 확인해야 합니다. 저장한 작품은 다시 열기·인쇄·SVG 내려받기를 지원합니다.

### 나만의 국기 만들기

사각형·원·선과 태극·별·하트·구름 등을 포함한 도형·문양 20종을 더해 칠합니다. 도형을 꾹 눌러 이동·크기 조절·삭제하고 태극 위·아래를 따로 칠할 수 있습니다. 종이 위 휴지통 안내는 약 2초 뒤 숨으며 다시 선택하면 나타납니다.

나라 이름을 직접 쓰거나 비워 둔 채 저장하세요. 빈 이름은 중복되지 않는 색상+동물 이름으로 자동 지정합니다. 저장하면 내 나라 카드에서 편집·펄럭임·SVG 내려받기·확인 후 삭제를 할 수 있습니다. 개인 국기는 실제 국가 지도·퀴즈 목록과 별도로 보관합니다. 펄럭임은 기본 하늘 또는 연결된 나라의 엽서 배경을 선택하며 바람 세기와 일시정지를 지원합니다. 그래픽을 지원하지 않는 환경에서는 저장한 그림을 평면으로 표시합니다.

## 기록과 백업

설정, 탐험 도장, 색칠 초안과 갤러리는 **현재 기기·브라우저·사이트 주소의 저장 공간**에 보관합니다. 다른 기기나 다른 주소로 자동 동기화하지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 종료 또는 저장 공간 문제로 기록이 사라질 수 있으므로 중요한 작품은 SVG로 내려받으세요.

초안은 다시 열 수 있지만 이전 방문의 실행 취소 이력 전체를 복원하지는 않습니다. 공식 색칠 작품의 SVG에는 붓질을 표현한 래스터 이미지가 포함될 수 있으므로 모든 붓질이 순수 벡터인 것은 아닙니다.

## 소스 실행과 검사

이 저장소는 React 19·Vite 6·MapLibre GL 6 기반입니다. Node.js 20.19 이상 또는 22.12 이상의 지원 버전과 npm을 사용합니다. `package-lock.json`을 유지하고 설치합니다.

```sh
npm ci
npm run dev
```

프로덕션 빌드와 기존 전체 검사:

```sh
npm run build
node --test tests/*.test.mjs
npm run check:learning
node scripts/build-polar-learning.mjs --check
```

Sites 서버 검사만 실행하려면 `npm run test:sites`를 사용합니다. 이 4개 검사는 현재 전체 128개에 이미 포함되므로 검사 수에 다시 더하지 않습니다. 빌드 결과를 로컬에서 확인하려면 `npm run preview`를 사용합니다.

일반 빌드에는 이미지 생성이나 사용자 백업 원본의 재다운로드가 필요 없습니다. 사용 중인 국기·엽서·데이터 파일은 소스에 포함되어 있습니다.

## 배포와 ZIP 구분

`npm run build`는 `dist/client/`, `dist/server/index.js`, `dist/.openai/hosting.json`을 생성합니다.

| 배포·자료 형태 | 사용할 내용 |
|---|---|
| 현재 공개 앱 | 위의 앱 링크로 바로 이용 |
| Sites | 기존 `.openai/hosting.json`의 프로젝트를 재사용하고 client·Worker를 함께 배포 |
| 일반 정적 웹 호스팅 | `dist/client/` 안의 파일 전체를 웹 서버 루트에 업로드 |
| 최신 실행 ZIP | `kids-world-atlas-web-20261022.zip`; 컴파일된 앱과 `README-DEPLOY.txt` |
| GitHub 업로드용 소스 ZIP | `kids-world-atlas-source-20261022.zip`; 소스·에셋·README·검사·출처 |
| 소스 저장소 | `src/`, `public/`, 설정·스크립트·검사; 수정 후 Node/npm 빌드 필요 |
| 교육·극지 콘텐츠 ZIP | 원고·출처 또는 그림 자료; 실행 앱 ZIP과 별도 |

완성 실행 ZIP은 압축을 풀어 웹 서버 루트에 올리면 되며 Node/npm 재빌드는 필요하지 않습니다. HTML을 두 번 클릭하는 `file://` 실행은 지원하지 않습니다. 하위 경로에 배포하려면 Vite의 경로 설정과 자료 URL을 함께 검토해야 합니다.

이전 v31 실행 ZIP은 150,752,270바이트·706파일이며, 실제 배포에 제출한 클라이언트 705파일과의 바이트 비교 및 ZIP CRC 검사를 통과했습니다. 저장소에는 해당 ZIP의 검증 기록이 있으며 ZIP 파일 자체가 소스에 포함되어 있다는 뜻은 아닙니다.

기존 v26 전용 `scripts/package-final-web-app.py`는 해당 버전의 해시를 검증하므로 최신판 포장에 그대로 쓰지 마세요. 새 실행 ZIP은 `scripts/package-mobile-web-app.py`에 새 파일명·출처 커밋·버전·README·기록 경로를 지정하는 방식으로 준비합니다. 이전 배포와 교육 ZIP을 덮어쓰지 않습니다.

기존 197개국 엽서는 원래 40장 + 생성 70장 + 사용자 백업 통합 87장입니다. 그린란드·남극 2장은 별도로 관리합니다. 한 나라의 대체 장면이 여러 장 있어도 국가 완료 수를 늘리지 않습니다. 새 그림을 통합할 때는 ISO 국가 코드로 연결하고 장면 캡션·미리보기·큰 그림·검수 기록을 함께 갱신하세요. 미리보기는 최대 640px WebP이며 큰 그림은 열었을 때만 요청합니다. 원본을 업스케일하거나 사용자 그림의 생성 프롬프트를 추정하지 않습니다.

일반 앱 빌드와 별도로 원고를 수정할 때:

```sh
npm run build:learning
npm run check:learning
node scripts/build-polar-learning.mjs
node scripts/build-polar-learning.mjs --check
```

원래 197개국 원고와 추가 지역 원고를 나눠 생성합니다. `sources/README.md`에서 출처와 기존 문장을 보존하는 기준을 확인하고, 나라·수도·인구·엽서 연결은 관련 자료와 함께 검토하세요. 그림 제작·통합 방법은 `artwork/README.md`, 현재 수량은 `artwork/postcard-progress.json`을 참고합니다.

## 데이터와 라이선스

- 인구는 UN World Population Prospects 2024 중위 추계의 **2025년 7월 1일 값**입니다. 2026년 실시간 인구나 센서스라고 표시하지 않습니다. 그린란드는 Statistics Greenland 등록 인구를 별도로 사용하며 남극에 국가 인구를 만들지 않습니다.
- 국가명·수도·정부 소재지·유산의 출처와 예외는 `sources/README.md` 및 국가별 자료에 기록합니다. 전체 수도 핀의 독립적인 정밀 위치 대조는 아직 완료하지 않았습니다.
- 국가 목록·기초 자료는 ODbL 1.0, `lipis/flag-icons`와 Phosphor 아이콘은 MIT 등의 원본 고지를 유지합니다. 자세한 재사용 조건은 `THIRD_PARTY_NOTICES.md`와 각 라이선스 파일을 확인하세요.
- 공식 색칠 견본은 `flag-icons`의 4:3 표시용 SVG입니다. 각 나라 국기의 법정 비율·제작 규격을 모두 재현했다고 주장하지 않습니다.
- 엽서는 수채화·과슈 스타일의 학습용 일러스트입니다. 지도 측량 자료나 현장 사진으로 취급하지 않습니다.

## 확인한 범위와 남은 검수

확인한 대표 데스크톱 흐름은 무작위 시작, 나라·태그·키보드 검색, 이야기·엽서 열기와 닫기, 오답 재도전·세 별·자동 다음, 베트남 국기 키보드 색칠 100%·저장, 내 나라 카드 저장·새로고침 복원, 팝업 초점 복귀와 한영 긴 이름 표시입니다. 그래픽 미지원 안내와 이름 퀴즈·카드 탐험·평면 국기 대체 경로도 갖췄습니다.

다음 항목은 실사용 검수를 완료한 것으로 표시하지 않습니다.

- 실제 휴대폰·태블릿의 좁은/짧은 화면, 터치·회전·그리기·지우기·저장과 엽서 확대.
- WebGL2 지도, 반복 세계·핀·연속 이동·핀치와 GPU 3D 국기 펄럭임.
- 전체 수도 좌표의 독립적인 정밀 대조와 모든 199곳의 직접 조작.
- 화면낭독기, 실제 운영체제 움직임 줄이기, 정답 소리 음량과 어린이 반응.
- 실제 휴대폰의 초기 로딩 성능. 빌드는 통과하지만 큰 JavaScript 번들 경고가 남아 있습니다.

최신 구현·잔여 업무는 `TASKS.md`, 기능 요약은 `FEATURE_STATUS.md`, 마지막 직접 화면 검수는 `UIUX_FINAL_REVIEW_V31_20261003.md`, 배포·ZIP 증거는 `artwork/final-release.json`과 `artwork/ux-final-update-20261003/`에 기록되어 있습니다. 오래된 문서·작업 로그의 수량과 버전은 당시의 기록이며 현재 완료 수량은 이 README의 요약과 최신 작업표를 기준으로 확인하세요.
